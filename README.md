# Operating Systems Lab Programs

This repository contains my Operating Systems lab programs implemented in **C++**.

## Environment

- Language: C++
- Operating System: Ubuntu (WSL)
- Compiler: g++

## Folder Structure

Each program is stored in its own folder.

Example:

```
problem-name/
│
├── solution.cpp
└── README.md
```

- `solution.cpp` contains the implementation.
- `README.md` contains the problem statement and program details.
